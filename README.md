## Overview

Exam Anxiety Assessment Tool is a small HTML web project designed to help school and college students reflect on their anxiety around exams. The browser-based format provides a quick and accessible way to complete an assessment.

Rather than requiring a complicated application environment, the tool uses a simple assessment experience that is easy to open, inspect, and modify. It can support educational demonstrations, personal reflection, and other student-focused exam anxiety screening scenarios.
